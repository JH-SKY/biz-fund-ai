# 🏗️ [Biz-Fund-AI] 프로젝트 폴더 구조

## 1. 개요

본 문서는 **Biz-Fund-AI(비즈업)** 프로젝트의 전체 디렉토리 구조와 각 파일의 역할을 정의합니다.  
백엔드는 **router → service → repository → database** 4계층 흐름과 **도메인 중심 구조**를 엄격히 따릅니다.

> 마지막 업데이트: 2026-04-15

## 5. 전체 API 엔드포인트 현황

| 분류 | Method | Endpoint | 설명 |
|------|--------|----------|------|
| **인증** | POST | `/api/v1/auth/kakao` | 카카오 소셜 로그인/가입 |
| **인증** | POST | `/api/v1/auth/naver` | 네이버 소셜 로그인/가입 |
| **인증** | POST | `/api/v1/auth/logout` | Refresh Token 무효화 로그아웃 |
| **사용자** | GET | `/api/v1/users/me` | 내 프로필 조회 |
| **사용자** | PATCH | `/api/v1/users/profile` | 추가 프로필 설정 (관심분야 등) |
| **사용자** | DELETE | `/api/v1/users/withdraw` | 회원 탈퇴 (Soft Delete) |
| **사업장** | POST | `/api/v1/onboarding/verify-biz` | 사업자번호 진위 확인 |
| **사업장** | POST | `/api/v1/onboarding/register` | 온보딩: 사업장 최초 등록 |
| **사업장** | GET | `/api/v1/businesses/me` | 사업장 정보 조회 |
| **사업장** | PATCH | `/api/v1/businesses/me` | 사업장 정보 수정 |
| **사업장** | POST | `/api/v1/businesses/validate` | 매출/인원 입력값 실시간 검증 |
| **재무** | POST | `/api/v1/businesses/finance` | 신규 재무 정보 등록 |
| **재무** | GET | `/api/v1/businesses/finance/history` | 연도별 재무 이력 조회 |

## 6. 아키텍처 핵심 원칙 요약

```
[Client]
    │  HTTP Request
    ▼
[api/v1/*_router.py]        ← 요청 수신·응답 반환만 담당, 로직 없음
    │  Depends()
    ▼
[api/deps/*_deps.py]        ← JWT 검증, 현재 사용자/관리자 추출, 온보딩 가드
    │
    ▼
[domains/*/service.py]      ← 비즈니스 로직, 트랜잭션 관리, 외부 API 호출
    │
    ▼
[domains/*/repository.py]   ← DB 접근 전용, CRUD·필터 쿼리만 수행
    │
    ▼
[domains/*/model.py]        ← SQLAlchemy ORM (DB 테이블 구조, 도메인 내 통합 관리)
    │
    ▼
[database/postgres/base.py] ← DeclarativeBase + 전체 모델 일괄 등록 (Alembic 인식)
    │
    ▼
[PostgreSQL]
```

> **금지 사항**: Router에서 DB 직접 접근 ❌ | Service에서 ORM 직접 조작 ❌ | Repository에서 비즈니스 판단 ❌
