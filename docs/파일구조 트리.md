# 🏗️ [Biz-Fund-AI] 프로젝트 폴더 구조

## 1. 개요

본 문서는 **Biz-Fund-AI(비즈업)** 프로젝트의 전체 디렉토리 구조와 각 파일의 역할을 정의합니다.

## 7. 아키텍처 핵심 원칙 요약

```
[Client]
    │  HTTP Request
    ▼
[api/v1/*_router.py]     ← 요청 수신·응답 반환만 담당, 로직 없음
    │  Depends()
    ▼
[api/deps/*_auth.py]     ← JWT 검증, 현재 사용자/관리자 추출
    │
    ▼
[domains/*/service.py]   ← 비즈니스 로직, 트랜잭션 관리, 외부 API 호출
    │
    ▼
[domains/*/repository.py] ← DB 접근 전용, CRUD·필터 쿼리만 수행
    │
    ▼
[models/*/*.py]           ← SQLAlchemy ORM (DB 테이블 구조)
    │
    ▼
[PostgreSQL]
```

> **금지 사항**: Router에서 DB 직접 접근 ❌ | Service에서 ORM 직접 조작 ❌ | Repository에서 비즈니스 판단 ❌
