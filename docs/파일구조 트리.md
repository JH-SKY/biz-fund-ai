# 🏗️ [Biz-Fund-AI] 프로젝트 폴더 구조
## 1. 개요
본 문서는 **Biz-Fund-AI** 프로젝트의 전체 디렉토리 구조와 각 폴더/파일의 역할을 정의합니다. 특히 `src/app/` 내부의 실무형 아키텍처 구조를 상세히 기술하여 개발 일관성을 유지합니다.

---

## 2. 최상위 디렉토리 구조 (Root)
프로젝트 전체의 환경 설정 및 공통 문서를 관리합니다.

```text
Biz-Fund-AI/
├── backend/                # 🐍 FastAPI 백엔드 (모든 서버 로직의 본부!)
│   ├── src/
│   │   └── app/
│   │       ├── api/        # 1. 출입문: 외부 요청을 받아 각 부서로 연결하는 라우터
│   │       ├── agents/     # 2. 비즈몽의 뇌: LangGraph로 설계된 생각하는 AI 워크플로우
│   │       ├── chains/     # 3. 배달원: 특정 데이터를 가져와 LLM에 전달하는 RAG 로직
│   │       ├── core/       # 4. 관리실: 앱 전체 설정, 비밀번호(Secrets), 권한 관리
│   │       ├── database/   # 5. 창고 열쇠: 데이터베이스와 연결되는 세션 관리부
│   │       │   ├── postgres/ # - 일반 데이터용 (사용자 정보, 매칭 이력)
│   │       │   └── vector/   # - AI 지식용 (정책 공고문의 벡터 좌표)
│   │       ├── models/     # 6. 설계도: 실제 DB에 어떤 모양으로 저장할지 정하는 그릇
│   │       ├── schemas/    # 7. 검문소: 들어오고 나가는 데이터 형식이 맞는지 검사(DTO)
│   │       ├── services/   # 8. 외부 협력 업체: 공공데이터 API, 알림톡 등 외부 연동
│   │       ├── utils/      # 9. 공구함: 시간 계산, 로그 기록 등 공통 유틸리티
│   │       ├── worker/     # 10. 야간 작업반: 데이터 수집/색인 등 백그라운드 작업
│   │       └── main.py     # 11. 스위치: 서버를 켜고 끄는 전체 서비스 진입점
│   ├── tests/              # 🧪 시험장: 코드가 제대로 작동하는지 미리 테스트하는 곳
│   ├── .env                # 🔐 비밀 금고: 외부 노출 금지된 설정값(API Key 등)
│   ├── .python-version     # 파이썬 버전 명시
│   ├── .venv               # uv 전용 가상환경 격리 공간
│   ├── pyproject.toml      # 부품 목록: uv가 관리하는 프로젝트 의존성 명세
│   └── uv.lock             # 버전 잠금: 설치된 라이브러리 버전 고정
├── data/                   # 📄 지식 베이스: AI가 학습하거나 참고할 원본 데이터(PDF/CSV)
├── docs/                   # 📚 도서관: 프로젝트의 모든 설계 기록 및 로드맵 보관
│   ├── images/             # 설계 이해를 돕는 시각 자료 (ERD 등)
│   ├── 01_concept_requirements.md # 서비스의 존재 이유와 목표
│   ├── 02_system_architecture.md  # 시스템 전체 연결 구성도
│   ├── 03_data_design_spec.md     # 데이터 상세 정의 및 DB 설계도
│   ├── 04_experiment_test.md      # AI 성능 및 시나리오 테스트 결과
│   ├── 05_troubleshooting_log.md  # 에러 해결 기록 (사고 과정 훈련용)
│   ├── 06_UI_UX_Dive.md           # 화면 설계 및 사용자 경험 포인트
│   ├── Biz-Fund-AI_로드맵.md      # 14주간의 프로젝트 진행 지표
│   ├── 파일구조_트리.md           # (본 문서) 프로젝트 아키텍처 가이드
│   └── 문서가이드라인.md          # 통일된 문서 작성을 위한 규칙
├── frontend/               # 🎨 얼굴: 사용자에게 보여질 리액트 화면 (추후 개발)
├── .gitignore              # 🚫 제외 목록: 깃허브에 올리지 않을 개인 파일 설정
├── README.md               # 🚩 프로젝트 대문: 처음 오는 사람을 위한 가이드
└── docker-compose.yml      # 📦 컨테이너 설정: DB 등을 한 번에 띄우는 마법 설정
```
