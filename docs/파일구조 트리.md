# 🏗️ [Biz-Fund-AI] 프로젝트 폴더 구조

## 1. 개요

본 문서는 **Biz-Fund-AI(비즈업)** 프로젝트의 전체 디렉토리 구조와 각 파일의 역할을 정의합니다.  
백엔드는 **router → service → repository → database** 4계층 흐름과 **도메인 중심 구조**를 엄격히 따릅니다.

> 마지막 업데이트: 2026-04-15

## 4. backend/ — FastAPI 서버

### 4-1. 루트 설정 파일

```text
backend/
├── .env                      # 🔐 환경 변수 (DB URL, JWT Secret, API Key) — Git 제외
├── .python-version           # pyenv 기준 Python 버전 고정 (3.12)
├── alembic.ini               # Alembic 마이그레이션 메인 설정 파일
├── pyproject.toml            # uv 패키지 의존성 명세 (FastAPI, SQLAlchemy 등)
└── uv.lock                   # 설치된 라이브러리 버전 고정 파일
```


### 4-3. src/app/ — 애플리케이션 핵심

```text
backend/src/app/
├── main.py                   # FastAPI 앱 인스턴스 생성 + 모든 도메인 모델 선행 로드, 라우터 마운트, 헬스체크 엔드포인트
│
├── core/                     # ⚙️ 전역 설정 및 인증 유틸
│   ├── config.py             # 환경 변수 로드 (Settings 클래스, .env 바인딩)
│   ├── exceptions.py         # 전역 HTTP 예외 핸들러 등록
│   ├── response.py           # 표준 API 응답 포맷 헬퍼 (api_json)
│   └── security.py           # JWT 생성·검증, 패스워드 해싱 유틸
│
├── database/                 # 🗄️ DB 연결 관리
│   └── postgres/
│       ├── database.py       # 비동기 SQLAlchemy 엔진·세션 생성, get_db() DI 함수
│       └── base.py           # DeclarativeBase 정의 (순수 Base 클래스 — 모델 import 없음)
│   └── vector/               # 🔍 벡터 DB 연결 (향후 AI 검색 연동용, 예: pgvector)
│
├── agents/                   # 🤖 LangChain/LangGraph 에이전트 모음 (예정)
├── chains/                   # ⛓️  LLM 체인 정의 모음 (예정)
├── utils/                    # 🔧 공통 유틸 함수 모음 (예정)
├── worker/                   # ⚡ 백그라운드 작업·배치 워커 (예정)
│
├── domains/                  # 💼 도메인별 비즈니스 로직 + SQLAlchemy 모델
│   │                         #    각 도메인은 model / exception / schema / repository / service 세트
│   ├── auth/                 # [인증·사용자·관리자] 소셜 로그인, 로그아웃, 탈퇴, 관리자 계정
│   │   ├── exception.py
│   │   ├── model.py
│   │   ├── repository.py
│   │   ├── schema.py
│   │   └── service.py
│   │   ├── exception.py
│   │   ├── model.py
│   │   ├── repository.py
│   │   ├── schema.py
│   │   └── service.py
│   ├── business/             # [사업장] 사업장 등록·수정, 재무 스냅샷, 서류 관리
│   │   ├── exception.py
│   │   ├── interfaces.py     # 외부 서비스 인터페이스 (국세청 API 등)
│   │   ├── model.py
│   │   ├── repository.py
│   │   ├── schema.py
│   │   └── service.py
│   ├── policy/               # [정책] 정책 공고 마스터, 북마크, 맞춤 추천
│   │   ├── exception.py
│   │   ├── infrastructure.py # 외부 정책 데이터 수집 인프라 (공고 크롤링·연동)
│   │   ├── interfaces.py     # 외부 API 인터페이스 추상화
│   │   ├── model.py
│   │   ├── repository.py
│   │   ├── schema.py
│   │   ├── service.py
│   │   └── sync_service.py   # 외부 정책 데이터 동기화 서비스 (배치 연동)
│   ├── biz_pick/             # [비즈픽] 콘텐츠(아티클) 조회, 좋아요
│   │   ├── model.py
│   │   ├── repository.py
│   │   ├── schema.py
│   │   └── service.py
│   ├── diagnosis/            # [정밀진단] 사업장↔정책 매칭 판정, 가산점 시뮬레이션
│   │   ├── interfaces.py     # 진단 외부 인터페이스 추상화
│   │   ├── model.py
│   │   ├── repository.py
│   │   ├── schema.py
│   │   └── service.py
│   ├── chat/                 # [AI 상담] 비즈몽 채팅 세션, 메시지 이력
│   │   ├── exception.py
│   │   ├── interfaces.py     # LLM 외부 인터페이스 추상화
│   │   ├── model.py
│   │   ├── repository.py
│   │   ├── schema.py
│   │   └── service.py
│   ├── notification/         # [알림] 사용자 알림 발송 이력, 설정
│   │   ├── exception.py
│   │   ├── model.py
│   │   ├── repository.py
│   │   ├── schema.py
│   │   └── service.py
│   └── system/               # [시스템] 파트너 상담 리드, 배치 작업 이력
│       ├── model.py
│       ├── repository.py
│       └── service.py
└── api/                      # 🚪 외부 진입 계층 (Router + 의존성 주입)
    ├── deps/                 # FastAPI Depends() 의존성 모음
    │   ├── user_auth.py      # CurrentUser 추출 (JWT 검증)
    │   ├── admin_auth.py     # 관리자 인증 의존성
    │   ├── business_deps.py  # ActiveBusiness 가드 (온보딩 완료 여부 확인)
    │   ├── policy_deps.py    # PolicyServiceDep, OptionalBusinessId, RequiredBusinessId
    │   ├── biz_pick_deps.py  # BizPickServiceDep
    │   ├── chat_deps.py      # ChatServiceDep
    │   ├── diagnosis_deps.py # DiagnosisServiceDep
    │   ├── notification_deps.py # NotificationServiceDep
    │   └── system_deps.py    # SystemServiceDep
    └── v1/                   # API 버전 v1 라우터 세트
        ├── router.py         # v1 전체 라우터 집계 (모든 도메인 라우터 통합)
        ├── auth_router.py    # POST /auth/kakao, /auth/naver, /auth/logout
        ├── users_router.py   # GET /users/me, PATCH /users/profile, DELETE /users/withdraw
        ├── business_router.py # /onboarding/*, /businesses/*, /documents/*
        ├── policy_router.py  # GET|POST /policies/*, /policies/bookmarks
        ├── biz_pick_router.py # GET /biz-picks/*, POST /biz-picks/{id}/like
        ├── diagnosis_router.py # GET|POST /diagnoses/*, /simulations/*
        ├── chat_router.py    # POST|GET /chat/sessions/*, /chat/sessions/{id}/messages
        ├── notification_router.py # GET|PATCH /notifications/*, /notifications/settings
        └── admin_router.py   # /admin/* 전체 관리자 API
```
