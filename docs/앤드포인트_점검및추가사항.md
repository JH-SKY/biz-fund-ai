| **제안** | `/api/v1/admin/ai/regenerate` | **POST** | AI 요약 재생성 | 공고문이 복잡할 경우 AI 요약 결과가 마음에 안 들 때 다시 생성하는 기능 |

4. 향후 고려 사항
* 관리자 권한(`role`)을 별도로 두어 일반 사용자는 접근할 수 없도록 API Gateway 수준에서 강력한 보안 필터링이 반드시 동반되어야 함.

### [정밀진단 서비스 구간] 엔드포인트 검토 결과

1. 서비스 제공 가치 검토
* 이 서비스는 '정부지원금 합격률'을 높여주는 핵심 유료 모델 혹은 킬러 콘텐츠가 될 수 있음.
* 진단 결과에 따라 "지금 당장 신청 가능한 정책 TOP 3"를 바로 연결해주는 액션 버튼이 결과 조회 화면에 포함되어야 함.

2. 테이블 구조 정합성 검토
* 10번 테이블의 `raw_data (JSONB)` 컬럼에 진단 당시의 재무/고용 지표를 스냅샷으로 저장해야 함. (시간이 지난 뒤 지표가 바뀌어도 당시 진단 근거를 확인하기 위함)
* 진단 결과와 4번(policies) 테이블을 매칭하는 중간 테이블이나 로직이 API 내부에 구현되어야 함.
