# 06. UI/UX 설계서 — Biz-Up 전체 화면 설계

> **문서 목적**: 프론트엔드 AI(v0, Cursor) 또는 개발자가 이 문서 하나만으로  
> Biz-Up 전체 서비스의 컴포넌트와 화면을 즉시 구현할 수 있는 블루프린트.
>
> **대상 독자**: 프론트엔드 생성 AI, 프론트엔드 개발자, UI/UX 디자이너

---

## 0. 디자인 원칙

| 원칙 | 설명 |
|:---|:---|
| **결론 먼저** | 사장님은 바쁩니다. 점수·순위·금액을 화면 최상단에 즉시 노출합니다. |
| **숫자로 말하기** | "좋습니다" 대신 "65점 / 100점", "+20점 향상" 같은 수치를 사용합니다. |
| **액션 유도** | 모든 결과 화면엔 다음 행동(신청하기, 시뮬레이션하기 등) CTA가 있습니다. |
| **로딩 중에도 의미** | AI가 생각하는 동안 진행 단계를 텍스트로 보여줍니다. 공백 화면은 없습니다. |
| **입력 최소화** | 사용자가 직접 타이핑하는 횟수를 최소화. 자동 완성·버튼 선택을 우선합니다. |

---

## 1. 전체 페이지 구조 및 사용자 흐름

```
[P01. 랜딩 /]
    │ 로그인 클릭
    ▼
[P02. 로그인 /auth/login]
    │ 최초 가입
    ▼
[P03. 온보딩 /auth/onboarding]  ← 사업자번호 인증 + 기본 프로필
    │ 완료
    ▼
[P04. 메인 대시보드 /dashboard]
    ├── [P05. 비즈-픽 /picks]          ← 정책 카드 뉴스 피드
    ├── [P06. 정책 검색 /policies]      ← 정책 검색·북마크
    ├── [P07. AI 상담 /chat]            ← 비즈몽 에이전트 채팅 (핵심)
    │       ├── 진단 결과 뷰
    │       ├── 시뮬레이션 결과 뷰
    │       ├── RAG 검색 결과 뷰
    │       └── 동종업계 통계 뷰
    ├── [P08. 서류 보관함 /documents]   ← 서류 업로드·OCR
    ├── [P09. 알림 /notifications]      ← 비즈-핑 알림 목록
    ├── [P10. 프로필 /profile]          ← 사업장 정보·재무 수정
    └── [P11. 비즈-히스토리 /history]   ← 상담·신청 이력 타임라인
```

## 2. 페이지별 상세 설계

---

### [P01] 랜딩 페이지 (`/`)

**목표**: 서비스 가치를 10초 안에 전달하고 로그인으로 전환.  
**접근 권한**: 비로그인 전용 (로그인 상태면 `/dashboard` 자동 리다이렉트)

**레이아웃**:
```
┌─────────────────────────────────────────┐
│  HERO SECTION                           │
│                                         │
│  2026년 사장님들을 기다리는 정책 자금      │
│  ₩ 26,450,000,000,000  ← 카운트업 애니메이션│
│                                         │
│  [지역 선택 ▾]  [업종 선택 ▾]             │
│  [지금 확인하기 →]                        │
│   → 모달: "서울/음식점업 신청 가능 47건"  │
├─────────────────────────────────────────┤
│  서비스 미리보기 (Blur 처리)              │
│  비즈-픽 카드 3개 (블러)                  │
│  비즈몽 채팅 미리보기 (블러)              │
│  [상세 분석 시작하기 →]  → /auth/login   │
└─────────────────────────────────────────┘
```

**인터랙션**:
- 페이지 진입 시 숫자 카운트업 애니메이션 (0 → 26.4조, 2초, requestAnimationFrame)
- 지역+업종 선택 후 "조회하기" → 결과 모달 표시 (로그인 없이 공고 건수만 노출)
- 미리보기 영역 클릭 → `/auth/login` 이동

### [P02] 로그인 / 회원가입 (`/auth/login`)

**접근 권한**: 비로그인 전용

**레이아웃**:
```
┌─────────────────────────────────────────┐
│  [비즈업 로고]                           │
│                                         │
│  사장님, 어서오세요!                     │
│                                         │
│  [  카카오 로그인  ]                     │
│  [  네이버 로그인  ]                     │
│                                         │
│  정책자금 진단, 비즈-픽, AI 상담          │
│  모두 무료로 시작하세요.                  │
└─────────────────────────────────────────┘
```

**인터랙션**:
- 소셜 로그인 클릭 → OAuth 2.0 플로우 → `POST /auth/social-login`
- 최초 가입자 → 온보딩(`/auth/onboarding`)으로 이동
- 기존 가입자 → 대시보드(`/dashboard`)로 이동

### [P03] 온보딩 (`/auth/onboarding`)

**목표**: 사업자번호 하나로 최대한 자동 완성. 직접 타이핑 최소화.  
**접근 권한**: 로그인 필수, 온보딩 미완료 사용자

**레이아웃 — Step 1: 사업자번호 인증**:
```
┌─────────────────────────────────────────┐
│  [비즈몽 캐릭터]                         │
│  "안녕하세요 사장님! 사업자번호를          │
│   입력하면 제가 정보를 불러올게요 😊"     │
│                                         │
│  [ 123-45-67890         ] [인증하기]     │
│                                         │
│  ✅ 자동 완성됨:                         │
│     상호명: 라이언테크                   │
│     지역: 서울특별시 도봉구              │
│     업종: G47 (소매업)                  │
│     개업일: 2022-01-15                  │
└─────────────────────────────────────────┘
```

**레이아웃 — Step 2: 추가 정보 입력**:
```
┌─────────────────────────────────────────┐
│  현재 직원 수: [    3    ] 명            │
│                                         │
│  해당하는 항목을 선택해 주세요:           │
│  [✅ 특허 보유] [  벤처기업 ]           │

│  [#인건비지원] [#창업자금] [#저금리대출] │
│                                         │
│        [시작하기 →]                     │
└─────────────────────────────────────────┘
```

**API 연결**:
- `POST /onboarding/verify-biz` → 인증 결과로 폼 자동 채움
- `POST /onboarding/register` → 완료 후 대시보드로 이동

### [P07] AI 상담 — 비즈몽 채팅 (`/chat`)

이 페이지가 Biz-Up의 핵심입니다. 비즈몽 AI 에이전트와 대화하며 진단·시뮬레이션·검색·통계를 모두 처리합니다.

**전체 레이아웃**:
```
┌─ 세션 사이드바 (데스크탑) ─┬─ 채팅 영역 ──────────────────┐
│  [+ 새 상담]               │  [이전 대화 내역...]           │
│                            │                               │
│  ● 고용지원금 상담          │  ┌─────────────────────────┐  │
│    Apr 19                  │  │  에이전트 결과 카드        │  │
│  ● 경영안정자금 상담         │  │  (타입별 다른 UI)         │  │
│    Apr 15                  │  └─────────────────────────┘  │
│                            │                               │
│                            │  [메시지 입력창] [전송 →]      │
└────────────────────────────┴────────────────────────────────┘
```

#### 7-1. 로딩 상태 (에이전트 실행 중)

```
┌─────────────────────────────────────────┐
│  🤖  [비즈몽 아이콘 + 타이핑 점 3개 ...]  │
│                                         │
│  ⏳ AI가 맞춤 채점을 진행 중입니다...     │
│  ████████░░░░░░░░  (진행 바 애니메이션)   │
└─────────────────────────────────────────┘
```

단계별 텍스트 (2초 간격 순환):
1. "비즈몽이 사업장 정보를 확인하고 있습니다..."
2. "현재 접수 중인 정책 200개를 검토 중입니다..."
3. "AI가 맞춤 채점을 진행 중입니다..."

```typescript
interface PolicyCardProps {
```

## 4. 반응형 레이아웃 가이드

| 브레이크포인트 | 주요 변경 사항 |
|:---|:---|
| **Mobile** (< 768px) | 채팅 사이드바 숨김 → 햄버거 메뉴. 카드 1열. 하단 탭 내비게이션. |
| **Tablet** (768~1024px) | 사이드바 아이콘 모드. 카드 1~2열. |
| **Desktop** (> 1024px) | 풀 사이드바. 진단 결과 정책 목록 2열 그리드. |

하단 탭 내비게이션 (모바일):
```
[홈] [비즈-픽] [AI상담] [알림] [프로필]
```
