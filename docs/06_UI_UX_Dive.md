# 🏗️ 06_UI_UX_Dive

> **작성 원칙**: 11개 독립 페이지 + 공통 AI 위젯 연동. 데이터 기반 컨설팅 및 수익화 흐름 완성.

---

### [PAGE 01] 랜딩 페이지 (Landing) - 비로그인 전용
- **역할**: "내 돈을 찾아줄 수 있다"는 확신과 탐욕을 자극해 로그인을 유도함.
- **주요 기능**:
  - **상단**: 정책 자금 총액 카운팅 (실시간으로 숫자가 올라가는 효과).
  - **중앙**: [지역/업종] 퀵 선택 위젯 -> 클릭 시 "사장님 동네에 00건이 있습니다" 문구 팝업.
  - **하단**: AI 맞춤 컨설팅 예시 화면(이미지) 노출로 기대감 증폭.
- **흐름**: [퀵 조회] → [결과 확인] → [로그인 유도 버튼 클릭] → 02번 이동.

### [PAGE 02] 로그인 페이지 (Login)
- **역할**: 거부감 없는 빠른 진입.
- **주요 기능**: 카카오/네이버 소셜 로그인 버튼 (단일화).
- **흐름**: 로그인 성공 시 [기존 유저 → 04번 메인] / [신규 유저 → 03번 온보딩].

### [PAGE 03] 간단 정보수집 (Onboarding) - 최초 1회
- **역할**: 이탈 방지를 위해 '당근'을 주며 필수 데이터(사업자번호, 업종, 인원) 수집.
- **주요 기능**:
  - **동기 부여**: 상단에 "사장님 업종 평균 수혜액은 0,000만 원입니다" 고정 노출.
  - **간편 입력**: 사업자번호 입력 시 유효성 체크, 업종은 검색형으로 선택.
- **흐름**: 정보 입력 → [완료] → DB 저장 → 04번 메인 이동.

### [PAGE 04] 메인 페이지 (Main Dashboard)
- **역할**: 내 사업장의 현재 상태와 추천 공고를 한눈에 브리핑.
- **주요 기능 (화면 왼쪽)**:
  - **맞춤 건수**: 나에게 매칭된 정책 수 노출.
  - **비즈몽 연결**: [내 비서 만들기] 버튼 (클릭 시 11번 이동).
  - **통계**: 유사업종 대비 내 혜택 수준 인포그래픽.
  - **핵심정보**: 정책자금꿀팁, 핵심공고등 하나 카드형태로 보여주기 (누르면 상세페이지이동)
- **주요 기능 (화면 오른쪽)**:
  - **신호등 위젯**: 내사업장 🟢(안전), 🟡(주의), 🔴(보완) 상태 표시. 
  - **사업장 정밀진단**: 내사업장산태에대한 이유 및 컨설팅 제안
  - **상태 트래커**: 서류 접수/심사/완료 단계 표시 바.
  - **원픽 카드**: AI가 뽑은 가장 유리한 공고 1개를 최상단 배치.
  - **등록서류현황**: 내가등록한 서류목록(사업자등록증같은거) 등록하기버튼 추가
- **흐름**: 대시보드 확인 → 상세 내용 궁금 시 해당 카드 클릭하여 06, 07, 11번으로 이동.

### [PAGE 05] 정책 페이지 (Full List)
- **역할**: 전체 정책 공고를 탐색하고 필터링함.
- **주요 기능**: 지역, 업종, 기관별 필터 및 키워드 검색.
- **흐름**: 검색/필터 적용 → 결과 리스트 탐색 → 상세 보기 클릭 시 07번 이동.

### [PAGE 06] 맞춤정책 페이지 (Matching List)
- **역할**: 사장님에게 딱 맞는 공고만 모아서 AI 요약과 함께 제공.
- **주요 기능**: 
  - [신규], [마감임박] 등 상태별 탭 구분.
  - 카드마다 비즈몽의 **정책요약간단버전(AI 요약)** 배지 노출.
- **흐름**: 추천 공고 확인 → 관심 있는 공고 07번 상세 보기 이동.

### [PAGE 07] 정책 상세보기 (Policy Detail)
- **역할**: 복잡한 공고를 AI 요약으로 쉽게 이해하고 신청으로 연결.
- **주요 기능**: 
  - 최상단 **정책요약 상세버전** (배경색 강조).
  - 상단 **AI 적합도 판정** : 사장님, 이정책은 현재 조건에서 수혜가능성이 높습니다 !(비즈몽응원)
  - 대상, 금액, 기간 등 핵심 정보 표(Table) 정리.
  - [찜하기] 및 [비즈몽과 함께 신청 서류 준비하기] [정책 사이트이동] 버튼.

### [PAGE 08] 정보 페이지 (Biz-Pick Home)
- **역할**: 소상공인에게 필요한 꿀팁과 뉴스를 매거진 형태로 제공.
- **주요 기능**: 카테고리별(세무, 정책, 마케팅) 카드 뉴스 리스트.

### [PAGE 09] 상세 정보 페이지 (Biz-Pick Detail)
- **역할**: 뉴스 및 아티클의 상세 내용 독취.
- **주요 기능**: 본문 하단에 "이 글과 연관된 지원금 확인" 버튼 (06번으로 연결).

### [PAGE 10] 마이페이지 (My Page)
- **역할**: 개인 정보 관리 및 디지털 서류함 운영.
- **주요 기능**: 프로필 수정

### [PAGE 11] 비즈몽 (AI Agent Interface) - 핵심
- **역할**: 채팅을 통해 정밀 진단을 수행하고 수치 기반 시뮬레이션 제공.
- **주요 기능**:
  - **정밀진단**: 정밀진단정보입력 유도
  - **AI 컨설팅**: "부채 비율을 낮추면 확률이 00% 올라갑니다" 식의 상담 / 용어해석 등
  - **시뮬레이션**: 특허 취득, 인건비 절감 시나리오를 그래프로 시각화하여 보여줌.
  - **수익화**: 전문가와상담매칭, 서빙로봇, 키오스크등 실제 효과어필하며 영업
- **흐름**: 채팅 상담 → 데이터 수집 → 시뮬레이션 리포트 확인 → 04번 대시보드 상태 업데이트.

### [SHARED] 비즈몽 플로팅 위젯 (Floating AI Widget)
- **위치**: 모든 페이지 우측 하단 고정 (z-index 최상단).
- **작동**: 클릭 시 화면의 1/4 크기로 '미니 채팅창' 오픈.
- **주요 기능 (Context Awareness)**:
  - **공고 페이지(07번)에서 열릴 때**: 현재 보고 있는 공고의 제목과 내용을 AI가 이미 파악하고 있음.
  - **즉시 질문**: "이 공고 지원 대상이 저도 포함되나요?"라고 물으면 바로 분석 답변.
  - **용어 풀이**: 어려운 단어 드래그 시 "비즈몽에게 물어보기" 버튼 노출 -> 클릭 시 미니창에서 해석.
