🟠 Tier 2 — 운영 안정성 (High)
H1. APScheduler가 멀티 인스턴스에서 중복 실행됩니다

👉 선택지:

전용 워커 프로세스만 스케줄러 실행 (RUN_SCHEDULER=true 환경변수 가드)
DB 기반 분산 락 (예: pg_advisory_lock) 도입
아예 K8s CronJob이나 AWS EventBridge로 이관
