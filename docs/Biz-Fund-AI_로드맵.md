# 🚀 Biz-Fund-AI: 실무형 프로젝트 8단계 로드맵

> **시니어 PO의 한마디:** "코딩은 집을 짓는 망치질이고, 이 로드맵은 설계도입니다. 망치질부터 하면 집이 무너지지만, 설계를 따르면 빌딩이 됩니다."

---

### 🟢 [PHASE 1] 기획 및 요구사항 확정 (Planning)
* **목표:** 서비스의 존재 이유와 핵심 기능 정의
* **주요 작업:** 페르소나 설정, 기능 명세서 작성, 서비스 범위(Scope) 확정
* **현재 상태:** **진행 중 (약 90% 완료)**

### 🟡 [PHASE 2] 시스템 설계 및 아키텍처 (Architecture)
* **목표:** 데이터의 흐름과 시스템 구조 설계
* **주요 작업:** DB 스키마(ERD), API 명세서 작성, AI 프롬프트 체인 설계
* **포인트:** 나중에 고생 안 하려면 여기서 '데이터 정합성'을 잘 잡아야 함

### 🔵 [PHASE 3] 개발 환경 구축 (Dev-Ops Setup)
* **목표:** 실제 개발이 가능한 '현장 사무소' 세팅
* **주요 작업:** 가상환경(venv), Docker 세팅, 필요한 라이브러리(FastAPI, SQLAlchemy 등) 설치
* **포인트:** 보안을 위한 `.env` 설정과 로그 시스템 구축 필수

### 🟠 [PHASE 4] 데이터 레이어 및 크롤러 개발 (Data Layer)
* **목표:** AI가 학습하고 분석할 '원재료' 확보
* **주요 작업:** 정책 사이트 크롤러(Scrapy/Selenium), PDF 텍스트 추출 로직, Vector DB 저장
* **포인트:** 깨끗한 데이터가 정확한 상담 결과를 만듦 (GIGO: Garbage In, Garbage Out)

### 🔴 [PHASE 5] 핵심 비즈니스 로직 구현 (Core Engine)
* **목표:** 서비스의 심장인 'AI 컨설턴트' 제작
* **주요 작업:** RAG(검색 증강 생성) 파이프라인, 매칭 알고리즘, 감성 위로 텍스트 생성 로직
* **포인트:** 30년 차 시니어가 가장 빡세게 코드 리뷰할 구간

### 🟣 [PHASE 6] 인터페이스 및 라우터 구현 (API Development)
* **목표:** 서버와 외부를 연결하는 통로 개설
* **주요 작업:** FastAPI 라우터 분리, 소셜 로그인(OAuth 2.0), 유저별 상태 관리
* **포인트:** 프론트엔드 개발자가 일하기 편하게 API를 예쁘게 뚫어줘야 함

### ⚫ [PHASE 7] 프론트엔드 연동 및 MVP 제작 (UI/UX)
* **목표:** 유저가 실제로 만질 수 있는 화면 구현
* **주요 작업:** 화면 UI 개발, API 연동, 모바일 대응(PWA/Flutter)
* **포인트:** "중학생도, 60대 사장님도 1초 만에 이해하는 UI"가 목표

### ⚪ [PHASE 8] 테스트 및 실전 배포 (QA & Deploy)
* **목표:** 버그 수정 및 세상에 서비스 공개
* **주요 작업:** 단위/통합 테스트, 클라우드(AWS/GCP) 배포, 모니터링 세팅
* **포인트:** 실제 소상공인의 피드백을 받고 0.1v씩 개선해 나가는 단계

---

## 🛠️ 시니어의 전략 가이드
1. **순서는 유연하게:** 1~3단계까지는 순차적으로, 4~6단계는 기능별로 반복하며 개발합니다.
2. **기록의 힘:** 에러가 나거나 설계가 바뀔 때마다 `05_troubleshooting_log.md`에 기록하는 습관이 '경력직 같은 신입'을 만듭니다.
