## 1. 페이지 개요 및 목표
* **페이지 명칭:** 서비스 인트로 및 퀵 조회 (Landing)
* **경로(Path):** `/` (Root)
* **접근 권한:** **비로그인 사용자 전용 (Public)**
    * *System Logic:* 로그인 세션이 확인된 유저는 메인 대시보드(`/dashboard`)로 자동 리다이렉트 처리.

### 기획 의도 (Mission)
1.  **압도적 규모감 전달:** 26조 원의 예산 수치를 시각화하여 정보의 가치를 즉각 인지시킴.
2.  **개인화된 기대감 증폭:** 내 지역/업종에 맞는 공고 건수를 미리 보여주어 '내 돈'이 있다는 확신 제공.
3.  **회원가입 전환 유도:** 맛보기 정보를 통해 상세 분석에 대한 욕구를 자극하여 자연스러운 가입 유도.

---

## 2. 화면 구성 및 상세 기능 (Functional Spec)

### ① 히어로 섹션: 연간 정책 예산 전광판
* **UI 구성:** 화면 최상단 대형 숫자 텍스트 배치 (Hero Typography).
* **상세 로직:**
    * **카운트업 애니메이션:** 페이지 진입 시 숫자가 `0`에서 `26,450,000,000,000`까지 2초간 롤링.
    * **텍스트:** "2026년 사장님들을 기다리는 정책 자금 총액"
    * **포인트:** 3자리 콤마(,) 적용 및 '조', '원' 단위 강조.

### ② 인터랙션 섹션: 퀵 선택 위젯 (Pre-Matching)
* **UI 구성:** [지역 선택] + [업종 선택] 드롭다운 + [조회하기] 버튼.
* **상세 로직:**
    * **필수값 체크:** 지역/업종 미선택 시 "조건을 모두 선택해주세요" 안내 노출.
    * **결과 모달(Modal):** 조회 클릭 시 "(**지역명**) (**업종명**) 신청 가능금액 : (**금액**) " 문구 노출.

### ③ 하단 섹션: AI 맞춤 보고서 미리보기
* **UI 구성:** 실제 유저가 받게 될 여러서비스들 맛보기 체험(**비즈픽**(맞춤정보), **비즈핑**(맞춤알림), **비즈몽**(AI상담))
* **상세 로직:**
    * 주요 데이터는 **블러(Blur) 처리**하여 호기심 유발 및 보안 느낌 강조.
    * 이미지 또는 [상세 분석 시작하기] 버튼 클릭 시 로그인 페이지(`/login`)로 연결.

---

## 3. 유저 시나리오 (User Flow)

1.  **진입(Attention):** 접속하자마자 보이는 거대한 예산 수치로 신뢰 확보.
2.  **참여(Interest):** 가벼운 마음으로 자신의 지역과 업종을 선택하여 조회.
3.  **확신(Desire):** 팝업을 통해 실제 내 조건에 맞는 공고 개수를 확인.
4.  **전환(Action):** 더 자세한 내용을 보기 위해 로그인 페이지로 이동.

---

## 4. 예외 상황 및 운영 정책
* **뒤로가기 대응:** 로그인 페이지에서 이탈하여 다시 랜딩으로 올 경우, 선택했던 필터값이 유지되어야 함.
* **반응형 대응:** 모바일 환경에서 숫자가 잘리지 않도록 폰트 크기 최적화 및 위젯 세로 배치 전환.

# [PAGE 02] 로그인 페이지 (Login) 상세 기획안

> **상태:** 구현 예정  
> **우선순위:** ⭐⭐⭐⭐⭐ (최상)  
> **관련 페이지:** [PAGE 01] 랜딩, [PAGE 03] 온보딩, [PAGE 04] 메인 대시보드

---

## 1. 페이지 개요 및 목표
* **페이지 명칭:** 로그인 및 회원가입 (Login / Sign-up)
* **경로(Path):** `/login`
* **접근 권한:** **모든 유저 (Public)**
    * *System Logic:* 별도의 자체 회원가입 폼 없이 소셜 로그인으로 가입과 로그인을 통합 처리.

### 기획 의도 (Mission)
1. **진입 장벽 최소화:** 복잡한 아이디/비밀번호 입력 대신 클릭 한 번으로 끝나는 소셜 로그인 제공.
2. **신속한 유저 식별:** 기존 회원과 신규 회원을 즉시 구분하여 최적화된 다음 단계로 안내.
3. **신뢰감 형성:** 카카오, 네이버 등 대형 플랫폼 연동을 통해 서비스 보안에 대한 신뢰도 확보.

---

## 2. 화면 구성 및 상세 기능 (Functional Spec)

### ① 소셜 로그인 섹션
* **UI 구성:** 카카오 로그인 버튼, 네이버 로그인 버튼 (브랜드 가이드라인 준수 디자인).
* **상세 로직:**
    * **OAuth 2.0 연동:** 각 플랫폼의 API를 호출하여 유저 고유 식별값(ID) 및 필수 프로필 정보 수취.
    * **단일화 전략:** 이메일 가입 등 다른 옵션을 배제하고 소셜 버튼만 노출하여 선택의 고민 제거.

### ② 페이지 전환 로직 (Routing)
* **신규 유저:** 소셜 인증 성공 후 DB에 해당 유저 정보가 없을 경우 **[PAGE 03] 온보딩**으로 이동.
* **기존 유저:** 소셜 인증 성공 후 이미 가입된 유저일 경우 **[PAGE 04] 메인 대시보드**로 이동.
* **리다이렉트 정책:** 로그인 완료 후 이전 페이지(랜딩 등)에서 의도했던 동작이 있다면 해당 경로로 우선 연결.

---

## 3. 유저 시나리오 (User Flow)

1. **진입(Access):** 랜딩 페이지의 CTA 버튼 또는 직접 접속을 통해 로그인 페이지 진입.
2. **선택(Choice):** 본인이 선호하는 소셜 플랫폼(카카오 또는 네이버) 버튼 클릭.
3. **인증(Auth):** 플랫폼별 간편 인증 절차 수행.
4. **분기(Branch):**
    * 첫 방문자라면? 추가 정보 입력을 위한 온보딩 페이지로 이동.
    * 기존 사용자라면? 즉시 맞춤형 정책 정보를 보여주는 메인 대시보드로 이동.

---

## 4. 예외 상황 및 운영 정책
* **로그인 실패:** 네트워크 오류 등으로 인증 실패 시 "로그인에 실패했습니다. 다시 시도해주세요." 토스트 메시지 노출.
* **계정 중복:** 서로 다른 플랫폼(카카오/네이버)이라도 이메일 주소가 같을 경우 계정 통합 여부 확인 로직 고려(추후 검토).
* **취소 대응:** 소셜 로그인 창에서 '취소'를 누를 경우 다시 로그인 페이지에 머물며 에러 메시지 없이 대기.

# [PAGE 03] 온보딩 페이지 (Onboarding) 상세 기획안

> **상태:** 구현 예정  
> **우선순위:** ⭐⭐⭐⭐⭐ (최상)  
> **관련 페이지:** [PAGE 02] 로그인, [PAGE 04] 메인 대시보드

---

## 1. 페이지 개요 및 목표
* **페이지 명칭:** 최초 정보 수집 (Onboarding)
* **경로(Path):** `/onboarding`
* **접근 권한:** **신규 가입 유저 전용 (Private)**
    * *System Logic:* 가입 후 최초 1회만 노출되며, 정보 입력 완료 시 DB의 '온보딩 완료' 플래그를 업데이트하여 재진입 방지.

### 기획 의도 (Mission)
1. **이탈 방지 장치(당근):** 입력 과정의 지루함을 상쇄하기 위해 예상 수혜액을 지속적으로 노출하여 동기 부여.
2. **정교한 매칭 기반 마련:** 정책 자금 분류의 핵심 기준인 사업자번호, 업종, 인원수를 정확하게 수집.
3. **심리적 허들 완화:** '간단 정보'임을 강조하고 입력 단계를 직관적으로 구성하여 완주율 제고.

---

## 2. 화면 구성 및 상세 기능 (Functional Spec)

### ① 동기 부여 헤더 (Sticky Header)
* **UI 구성:** 화면 상단 고정 바(Bar) 형태.
* **상세 로직:**
    * **고정 문구:** "사장님 업종의 평균 수혜액은 **0,000만 원**입니다."
    * **시각 효과:** 강조 색상을 사용하여 유저가 정보를 입력하는 동안 목표 금액을 계속 인지하도록 유도.

### ② 간편 입력 폼 (Input Form)
* **사업자등록번호:**
    * **유효성 체크:** 10자리 숫자 형식 검증 및 하이픈(-) 자동 생성.
    * **실시간 피드백:** 형식에 맞지 않을 경우 "올바른 사업자번호를 입력해주세요" 안내 노출.
* **업종 선택:**
    * **검색형 UI:** 키워드 입력 시 관련 업종 리스트가 자동 완성되는 검색 기능 제공.
    * **대분류/중분류 매핑:** 유저가 선택한 키워드를 정책 분류 코드와 연동하여 정확도 확보.
* **상시 근로자 수:**
    * **숫자 입력:** 본인 제외 현재 근무 중인 인원수 입력 (0명 포함 가능).

### ③ 완료 및 데이터 처리
* **버튼:** [분석 결과 확인하기] 또는 [완료] 버튼.
* **데이터 흐름:** 입력값 전송 → 유저 프로필 DB 저장 → **[PAGE 04] 메인 대시보드**로 리다이렉트.

---

## 3. 유저 시나리오 (User Flow)

1. **진입(Start):** 소셜 로그인 직후 신규 유저 판별 시 온보딩 페이지로 자동 진입.
2. **인지(Motivation):** 상단에 노출된 '업종 평균 수혜액'을 보며 정보 입력의 가치 확인.
3. **입력(Input):** 사업자번호, 업종, 인원수를 순차적으로 입력 (유효성 검사 포함).
4. **완료(Success):** 완료 버튼 클릭과 동시에 DB에 정보가 기록되며 나만의 맞춤형 메인 화면으로 이동.

---

## 4. 예외 상황 및 운영 정책
* **중도 이탈:** 정보 입력 중 브라우저 종료 시, 재로그인 시 다시 온보딩 페이지로 진입시켜 데이터 수집 강제.
* **업종 미검색:** 검색 결과에 원하는 업종이 없을 경우를 대비해 '기타' 또는 '직접 입력' 옵션 검토.
* **데이터 검증:** 입력된 사업자번호의 휴폐업 여부 등 실제 국세청 데이터 연동 여부는 추후 고도화 단계에서 결정.

> **우선순위:** ⭐⭐⭐⭐⭐ (최상)

## 1. 페이지 개요 및 목표
* **페이지 명칭:** 메인 대시보드 (Main Dashboard)
* **경로(Path):** `/dashboard`
* **접근 권한:** **로그인 및 온보딩 완료 유저 전용 (Private)**
    * *System Logic:* 온보딩 미완료 유저 접속 시 `/onboarding`으로 강제 리다이렉트.

### 기획 의도 (Mission)
1. **직관적인 현황 브리핑:** 내 사업장이 받을 수 있는 혜택과 현재 상태를 시각적 요소(신호등, 통계)로 즉각 전달.
2. **AI 기반 우선순위 제안:** 수많은 공고 중 유저에게 가장 유리한 '원픽'을 제안하여 탐색 비용 감소.
3. **서비스 연결 허브:** 비즈몽(AI 상담), 서류 관리 등 주요 기능으로의 자연스러운 이동 유도.

---

## 2. 화면 구성 및 상세 기능 (Functional Spec)

### ① 좌측 영역: 맞춤 브리핑 및 통계 (Left Section)
* **맞춤 정책 건수:** 온보딩 시 입력한 데이터를 바탕으로 실시간 매칭된 총 공고 수 노출.
* **비즈몽 연결 버튼:** [내 비서 만들기] 버튼 배치. 클릭 시 **[PAGE 11]** AI 에이전트 채팅 화면으로 이동.
* **혜택 수준 인포그래픽:** 유사업종/매출 규모 대비 나의 정책 수혜 수준을 비교 그래프로 시각화.
* **핵심 정보 카드:** '정책자금 꿀팁' 또는 '이달의 핵심 공고'를 카드 형태로 노출. 클릭 시 상세 페이지 이동.

### ② 우측 영역: 정밀 진단 및 트래커 (Right Section)
* **원픽(One-Pick) 카드:** AI 알고리즘이 분석한 유저 최적화 공고 1개를 최상단에 강조 배치.
* **사업장 신호등 위젯:** 🟢(안전), 🟡(주의), 🔴(보완) 아이콘으로 현재 사업장 준비 상태 표시.
* **정밀 진단 & 컨설팅:** 신호등 상태에 대한 구체적인 이유 설명 및 개선을 위한 컨설팅 방향 제안.
* **상태 트래커 (Status Bar):** 신청 중인 정책의 단계(서류 접수 → 심사 중 → 완료)를 진행 바 형태로 표시.
* **등록 서류 현황:** 사업자등록증 등 현재 등록된 서류 목록 리스트업 및 [추가 등록하기] 버튼 제공.

---

## 3. 유저 시나리오 (User Flow)

1. **진입(Overview):** 로그인 직후 대시보드에서 매칭된 정책 건수와 사업장 안전 점수(신호등) 확인.
2. **탐색(Analysis):** 인포그래픽과 정밀 진단 내용을 보며 내 사업장의 보완점 파악.
3. **실행(Action):** AI가 뽑은 '원픽 카드'를 확인하거나 더 궁금한 점은 '비즈몽' 버튼을 눌러 상담 시작.
4. **이동(Navigation):** 구체적인 공고 내용이나 서류 관리가 필요할 경우 해당 카드를 클릭하여 상세 페이지로 이동.

* **피드백 상세 리스트:** 유저가 누른 `👎` 사례를 사유별(정보 오류 / 실제 상황과 다름 / 용어 어려움)로 분류 노출.
사용자가 텍스트 피드백을 남기면 노출.
* **상담 로그 복기:** 피드백 시점의 **전체 대화 맥락(Context)**과 당시 적용된 매칭 로직을 한 화면에서 확인.
* **오답 정정 노트:** 관리자가 직접 "이 질문에는 ~라고 대답해"라고 가이드라인을 입력하면 로직에 즉시 반영.

### ② 시스템 건강 상태 및 비용 (System Health & Monitoring)
* **실시간 서비스 신호등:** 서버 상태를 정상(🟢), 지연(🟡), 장애(🔴)로 직관적 표시.
* **성능 트래커:** 비즈몽의 **평균 응답 속도(Latency)** 및 에러 발생률을 실시간 그래프로 시각화.
* **비용 모니터링:** 오늘 사용한 AI 모델(API) 토큰 비용을 실시간 금액으로 환산하여 노출.

### ③ 비즈픽 & 콘텐츠 관리 (Content Management)
* **AI 카드 뉴스 제작:** 정책 공고 URL 입력 시 AI가 3줄 요약 및 카드 뉴스 초안 자동 생성.
* **노코드 에디터:** 디자인 도구 없이 웹상에서 텍스트와 이미지를 즉시 수정하여 게시판 발행.
* **연관 정책 매핑:** 콘텐츠 하단에 노출될 '추천 지원금' 버튼을 AI가 자동 제안하거나 수동 연결.

### ④ 비즈니스 전략 대시보드 (Business Insights)
* **미충족 수요 분석:** 유저가 물어봤으나 **'매칭 결과 0건'**이었던 키워드 추출 (신규 정책 수집 우선순위 결정).
* **수익 전환 통계:** 전문가 상담 예약 건수 및 솔루션(로봇/키오스크 등) 클릭률/전환율 리포트.

2. **검수:** `👎` 피드백이 누적된 정책 로직을 확인하고 '오답 정정 노트'를 통해 즉시 교정.
3. **발행:** 신규 정책 공고를 '비즈픽' 에디터에 넣고 AI가 만든 카드 뉴스를 검수 후 예약 발행.

# [SHARED] 비즈몽 플로팅 위젯 (Floating AI Widget) 상세 기획안

> **상태:** 구현 예정  
> **우선순위:** ⭐⭐⭐⭐⭐ (최상)  
> **적용 범위:** 서비스 전체 페이지 (Global Floating UI)

---

## 1. 개요 및 목표
* **명칭:** 비즈몽 퀵 헬퍼 (Floating Widget)
* **위치:** 모든 화면 우측 하단 고정 (z-index 최상단 배치)
* **작동 방식:** 아이콘 클릭 시 화면의 약 1/4 크기로 '미니 채팅 레이어' 오픈.

### 기획 의도 (Mission)
1. **맥락 기반 상담 (Contextual Help):** 유저가 어떤 페이지를 보든 해당 콘텐츠를 기반으로 즉각적인 피드백 제공.
2. **탐색 허들 제거:** 어려운 용어나 복잡한 공고 내용을 페이지 이동 없이 즉시 해결하여 체류 시간 및 신뢰도 향상.
3. **상시 접근성:** 궁금한 점이 생겼을 때 즉시 질문할 수 있는 통로를 열어두어 고객 경험(UX) 최적화.

---

## 2. 화면 구성 및 상세 기능 (Functional Spec)

### ① 맥락 인식 기능 (Context Awareness)
* **상세 페이지 연동 (07번):** 유저가 특정 정책 공고를 보고 있을 때 위젯을 열면, AI가 해당 공고의 제목과 주요 자격 요건을 자동으로 로드함.
    * **자동 제안 질문:** "이 정책의 나이 제한이 저와 맞나요?", "제출 서류가 뭐가 필요하죠?" 등 칩(Chip) 형태의 추천 질문 노출.
* **데이터 동기화:** 위젯에서 나눈 짧은 대화 내용은 이후 **[PAGE 11] 비즈몽 상세 상담** 시 히스토리로 그대로 유지.

### ② 용어 즉시 풀이 (Text Selection Tooltip)
* **드래그 인터랙션:** 본문 내 어려운 단어(예: 출연금, 가점 사항 등)를 드래그하면 텍스트 상단에 [비즈몽에게 물어보기] 버튼 노출.
* **미니창 출력:** 버튼 클릭 시 플로팅 위젯이 열리며 해당 단어의 사전적 의미와 실무적 해석을 제공.

### ③ 퀵 메뉴 및 상태 표시
* **현재 상태 브리핑:** "사장님, 현재 신청 가능한 정책이 3건 더 있습니다!"와 같은 짧은 알림 배지 노출.
* **전체 화면 전환:** 미니 채팅창 상단의 확장 버튼 클릭 시 상세 상담 페이지(11번)로 전환.

---

## 3. 유저 시나리오 (User Flow)

1. **발견(Trigger):** 정책 상세 페이지를 읽다가 어려운 행정 용어를 발견하고 당황함.
2. **실행(Action):** 해당 단어를 드래그하여 [비즈몽에게 물어보기]를 누르거나 우측 하단 위젯 아이콘 클릭.
3. **해결(Solution):** 페이지를 벗어나지 않은 채 미니창에서 AI의 답변("사장님, 이 용어는 ~라는 뜻입니다")을 확인.
4. **연결(Bridge):** 추가 상담이 필요하다고 느끼면 [상세 상담하기]를 눌러 전체 화면에서 정밀 진단 시작.

## 4. 예외 상황 및 운영 정책
* **화면 가림 대응:** 주요 버튼(신청하기 등)을 가리지 않도록 모바일에서는 아이콘 크기 최적화 및 위치 조정 기능 고려.
* **중복 로딩 방지:** 페이지 이동 시마다 대화 내용을 새로 고침하지 않고, 세션 기반으로 부드럽게 유지.
* **무응답 처리:** 네트워크 불안정으로 AI 답변이 늦어질 경우 "비즈몽이 공고문을 꼼꼼히 읽고 있어요. 잠시만 기다려주세요!" 메시지 노출.
