## 문서 작성 원칙

1. **코드와 동기화**: 모든 API 명세와 DB 스키마는 실제 구현 코드(`router.py`, `model.py`)와 100% 일치해야 합니다. 변경 시 해당 문서도 함께 업데이트하세요.

2. **독자별 목적 분리**: 각 문서는 명확한 타겟 독자와 역할을 가집니다. 하나의 문서에 모든 것을 담으려 하지 마세요.

3. **예시 우선**: 추상적인 설명보다 실제 JSON 예시, 코드 스니펫, 다이어그램이 독자에게 더 빠릅니다.

4. **AI 친화적**: 프론트엔드 생성 AI(v0, Cursor 등)가 이 문서를 읽고 바로 코드를 생성할 수 있는 수준의 구체성을 유지하세요.
