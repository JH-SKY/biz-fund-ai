## 2. 전체 기간 요약

> **📅 총 14주 과정**

| 기간 | 주요 마일스톤 |
| :--- | :--- |
| **1~4주** | 백엔드 / DB / 정책 / 진단 엔진 |
| **5~8주** | 프론트 / 온보딩 / 진단 / 결과 UI |
| **9~10주** | RAG + LangChain |
| **11~12주** | LangGraph + AI Agent |
| **13~14주** | 배포 / QA / 운영 보완 / 발표 준비 |

* **내용:** Retriever, Prompt 체인, 요약 체인 및 질의응답 체인 구성

* **반영 주차:** 11주차
* **내용:** State, Node, Edge 설계를 통한 추가질문/검색/설명/제안 흐름 완성

### 🧠 AI Agent
* **반영 주차:** 12주차
* **내용:** Tool 호출(DB/검색), 사용자 상태 반영, 전략 제안 및 문맥 반영 채팅
